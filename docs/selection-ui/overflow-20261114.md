# スマホの選択フィルターのはみ出し修正

「女の子：衣装セット」で衣装を選択済みにすると、右端の「キャラ固有」「メンズ」が切れていました。直前の公開版 `1a49c692938229e5b5502d143382efed75a7fbe7` で再現しています。

原因は、元の人物フィルターの `width:100%` に、共通スタイルの左右12pxの余白が加算されたことです。393pxの画面ではダイアログの右端385pxに対してボタン列の右端が396pxとなり、枠の外側が隠れていました。従来の試験は表情の選択画面で幅を調べており、6ボタンの衣装セット画面を検証できていませんでした。

## 変更

- 直下のフィルター列は左右の余白を含めた内側の幅へ収めます。
- ボタンの高さを内容に合わせ、長いラベルと拡大文字は折り返します。ボタン幅は親の幅を超えず、最小幅44px・最小高さ40pxを維持します。候補やボタンは削除していません。
- 修正後、同じ393px画面のボタン列は幅351px・右端372pxとなり、検索欄と同じ右余白を確保します。
- 保存処理・候補データ・既存のコールバック・ホラーの本文スクロールは変更していません。生成HTMLの製品差分はCSSの2行です。
- PWAのキャッシュ名を `seaart-tool-pwa-picker-ui-20261114-v2:` に更新し、更新試験の起点を直前の公開版にしました。
