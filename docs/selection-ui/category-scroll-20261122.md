# 分類一覧のスワイプ修正

「表示設定 → 分類」で項目が多いと、一覧に触れても下の分類まで移動できませんでした。高さを制限している外側の設定パネルの中に、内容と同じ高さのスクロール領域が残っていました。内側の `overscroll-behavior: contain` が操作を止めるため、外側へスクロールが伝わりません。

表示設定内の分類・並び順パネルは `overflow: visible` と `overscroll-behavior: auto` にし、外側の設定パネルがスクロールを受け持つようにしました。外側の高さ制限と背景へのスクロール伝播防止、4ボタンの横一列表示、既存の分類を選ぶ処理を保持しています。変更は既存CSSルールへの2宣言追加だけです。HTMLの他の内容と、分類の候補・保存・生成・復元・UndoのJavaScriptは変更していません。

PWAのキャッシュ名を `seaart-tool-pwa-category-scroll-20261122-v1:` に更新し、前回公開版 `62efb3d3d491900d8ec17cc945f52fdd4418a98c` からの更新も検証します。保存キー・保存形式・初期化処理は変更しません。

## 検証内容

`npm run test:category-scroll` は3ケースです。

- 直前の公開版で同じ画面と操作を行い、タッチ・ホイールの動きを記録します。同じ保存データのまま修正版を読み込み、上下のスワイプとホイールで移動し、最下部の実在する分類をタップして適用できることを検査します。保存データ・名前付き保存・履歴・Undo・生成済みの出力も比較します。旧版のスクロール伝播はブラウザーによって異なるため、旧版が必ず失敗することはCIの条件にしません。
- CDPのtouchStart/touchMove/touchEndだけで79件の分類一覧の最後まで移動し、最後の分類をタップします。スクロール位置の直接代入やscrollIntoViewによって移動を代用しません。最下部でさらにスワイプしても背景が動かないことを確認します。
- 幅320/393/844px、縦向き・横向き、通常文字と実際の分類ボタンを18pxに拡大した状態で、キャラクター・人物衣装・生物・武器の分類を確認します。操作で候補が選ばれず、設定が維持され、背景にスクロールが伝わらず、横一列の操作部分と閉じる操作も維持されることを検査します。
