# 選択画面の上部と下部の整理

分類・並び順・一覧/カード切替が上部の複数箇所に分かれ、スマートフォンで候補を表示できる範囲が狭くなっていました。上部をタイトル・表示設定・閉じるへ整理し、補助操作を表示設定へまとめました。下部には選択状況と閉じるを置き、スクロールしても操作を終えられます。

## 操作と互換性

- 「表示設定」に既存の分類・並び順・一覧/カードのコントロールを横一列に配置します。検索と主要な絞り込みは画面に残します。補助操作の内容、選択処理、初期の一覧表示を維持します。
- 下部の件数は検索結果のチェック数から推定せず、現在の設定値や既存の選択中サマリーを参照します。人物・ポーズ・生物・状況/関係・背景・武器などの候補を対象とし、検索やページ切替によって選択が見えなくなっても保持します。
- 件数として数えにくい専用編集画面は編集状況を表示します。保存式の怪異編集では「保存するまで変更は未確定」と表示し、既存の保存/キャンセルも残します。
- 下部の閉じるは既存ヘッダーの閉じるを呼び出します。即時反映の画面と下書きを明示的に保存する画面、それぞれの動作を維持します。
- 漫画のメニューは元のactions要素内でまとめ、ネイティブの再描画時の後片付けが古いコントロールも検出できるようにします。検索のフォーカスとカーソル位置を保持します。
- 表示設定は外側のタップやEscapeで閉じられます。折りたたみ状態は画面を開いている間だけ持ち、保存項目を増やしません。
- 横向きでもヘッダー/下部バーを画面内に保ち、候補または本文をスクロールします。パレットの高さも確保します。

完成HTMLの変更は表示アダプター `src/current/selection-dialog-ui.js` の差し替えだけです。その他36スクリプト、圧縮した漫画ペイロード、候補定義、保存/復元/生成コードはバイト単位で一致します。保存キー・形式・初期化処理は変更しません。PWAのキャッシュ名を `seaart-tool-pwa-compact-picker-20261115-v2:` へ更新します。
