# ポーズ・体勢の組み立て画面

基本姿勢と手足の動作が同じ候補一覧に並び、選択後の編集内容も一覧から追いにくい状態でした。基本姿勢を専用の枠へ分け、選択中の動作をカードで調整できるようにしました。武器などの関連設定は折りたたみ、候補を表示する領域を確保しています。

## 操作

- 基本姿勢は通常1つ。別の姿勢を選ぶと、現在の基本姿勢だけを変更します。追加動作はそのままです。同じ姿勢を押すと、現在の姿勢の詳細を開きます。
- 選択中のカードに基本姿勢/追加動作の種別と組み合わせを表示します。例：`触れる／右手 → 自分の髪`。編集・複製・解除をカードから操作できます。
- 選択中のカード一覧は折りたためます。選択中フィルターではカードを直接表示します。
- 関連設定は初期状態で折りたたみます。武器・盾/防具・携帯品・エフェクト・位置/関係の5つの移動先を保持しています。対象設定で装備が必要なときの案内は、従来どおり表示します。
- 既存の左右、部位、対象、相手の部位、場所、向き、補足、強調度、並び順、複製、旧指定/追加候補の編集を保持します。候補定義、検索、お気に入り、分類、名前順も維持します。

## 保存互換性と変更範囲

保存済みの複数の基本姿勢を、読み込み時や画面を開いただけで減らしません。複数あるときに別の姿勢を選ぶと、編集中の基本姿勢（なければ先頭の1件）だけを変更します。その対象は画面に名前で表示します。明示的な複製による組み合わせも継続できます。

基本姿勢の変更ではID、共有する場所、重み、色、グループ、独自データを維持します。以前の姿勢に固有の向き・補足・部位などは、新しい姿勢で使えるものだけを引き継ぎます。変更は通常のUndo1回で戻せます。

保存形式・保存キー・`poseActionsVersion`・121件の候補定義を変更していません。折りたたみ状態は編集セッションだけに持ち、保存データへ追加しません。生物の擬人化編集は既存の下書き/保存/破棄の仕組みを使用します。

既存の生成・移行など38関数はバイト単位で維持し、既存関数の変更は表示に関する3関数です。その他の36スクリプトと漫画の圧縮ペイロードもバイト単位で一致します。PWAのキャッシュ名を `seaart-tool-pwa-pose-builder-20261115-v1:` へ更新しています。
