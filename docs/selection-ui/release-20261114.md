# 選択画面の統一 — 2026-11-14

メインと簡易漫画で異なっていた、選択画面の枠・見出し・検索欄・絞り込み・並び順・閉じる操作・選択状態・候補行を共通の見た目に整えました。

## 利用者に見える変更

- 検索欄は高さ44px・文字16px。閉じる操作は右端の44pxの「×」に統一し、読み上げ用の名前と既存の閉じる処理を維持します。
- 通常の文字候補は1行リストを基本とし、「表示：一覧／カード」で切り替えられます。同じ起動中はメインと簡易漫画で表示モードを共有します。再読み込み時は一覧へ戻ります。
- カード表示では元のカード構成・列設定を使います。ポーズの構造編集、色見本、背景のプリセットなどは専用の形式を維持します。
- 選択状態、星ボタン、入力欄、分類ボタンを共通の色・余白・角丸・文字サイズにします。簡易漫画のヘッダーメニューの表示名を「分類」「並び順」に合わせます。候補名は変更しません。
- 背景・風景、人物、生物、状況・関係、共通の候補、色、品質などの仕上げ設定、ホラーの設定、簡易漫画の人物・衣装・配色へ適用します。編集・保存・管理フォーム全体の作り直しは行いません。
- 狭い画面の閉じる文字のはみ出しを防ぎ、横向きでは内容全体をスクロールして候補に到達できるようにします。

## 実装と保存互換性

`src/current/selection-dialog-ui.js` を既存の最終スクリプトへ追加し、スクリプト数は37のままです。既存のコントロール・ID・クリック処理・入力値・候補定義を使い、ネイティブなダイアログ表示処理へ委譲します。表示切り替え用のボタンはデータ編集やUndo履歴へ書き込みません。

簡易漫画の遅延読み込み後は、対象のShadow DOMへ同じスタイルを1回だけ追加します。再描画への対応は開いている選択画面の中だけを監視し、閉じると解除します。document全体の監視は追加しません。

検索中の値・フォーカス・カーソル、選択結果、星、メインと簡易漫画の保存分離、JSONと名前付き保存を維持します。保存キー・バージョン・形式を変更せず、既存の「設定確認・修正」も残します。候補マスターを含む先頭36スクリプトと簡易漫画の圧縮ペイロードは変更していません。

PWAのシェルキャッシュ名を `seaart-tool-pwa-picker-ui-20261114-v1:` に更新しました。更新試験は直前のmain `30f2d2709c552f3727e6a3c0b1ab27464d30de38` から開始します。
