# Android確認版の短い確認表

この版はPRの確認用です。mainと公開版は更新していません。実機・実IME・SeaArt/PixAI画像の確認は未実施です。
最初に現在利用中の画面で設定JSONを書き出してください。画像合成の元画像・配置・未保存編集は別に保存してください。HTMLをコピーするだけでは端末データのバックアップになりません。

1. ZIPを展開し、`SeaArt_Background_ScreenEffects_Android_Check.html` をブラウザで開く。端末が直開きに対応しない場合はその結果を記録する。PWA更新は同梱資産を隔離HTTPSで配信して別に確認する。
2. 背景・風景で4タブを開く。前景に草花、中景に湖と小舟、遠景に雪山。カードの×、Undo、再表示、再読込で所属を確認する。
3. 人物とCreatureに武器・動作・魔法を設定。風景のみに切り替えて生成し、人物等が出力されず月光が残ることを確認。人物を編集してから人物ありへ戻し、最新の設定を確認する。
4. 仕上げ→画面エフェクト。ブルームは強さを選ぶ前はOFF、弱→強で英文が変わる。逆光と共存する。旧構図の背景ぼかしと新カードが同期し、×とUndoが一致する。
5. プリセットをプレビューしてキャンセル。補完／置換の違いを確認し、適用後はUndo一回で戻す。人物・モデルが変わらないことを確認する。
6. 漫画で背景・見せ方・効果を継承→個別→OFF→継承。背景OFFでも共通の見せ方は別に継承する。風景コマと人物コマの出力を比較し、複製・並べ替え後にも設定がついてくることを確認する。
7. 名前付き保存、履歴復元、JSON書出し／別の隔離環境への取込、再起動で層・強さ・範囲・コマ値を確認する。通常画像／漫画を交互に7回生成し、容量エラーが毎回出ないことを確認する。
8. 縦・横、文字拡大、長い候補名、キーボード表示中に、候補・閉じる・解除・適用までスクロールしてタップできることを確認する。
9. 必要ならSeaArt/PixAIで実画像を確認し、モデル名・設定・結果を記録する。背景中心はピクセル範囲の限定を保証しない。

GitHub PWA、Sites、ダウンロードHTML、簡易漫画の保存領域は自動で転送されません。新形式のJSONは旧mainで拒否される場合があります。コードを戻す作業と保存データを戻す作業は別です。
