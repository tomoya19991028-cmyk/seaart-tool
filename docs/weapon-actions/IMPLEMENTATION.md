## 分類と候補

既存valueをキーにした表示メタデータを `src/current/weapon-actions.js` に置く。
標準37武器は通常候補。盾3件は既存の盾・防具に残す。
分類編集、非表示、お気に入り、英語の独自編集は既存の保存元を使用する。
`scythe` の基本表示も「大鎌」に統一し、編集名を優先する。

## 保存・参照

既存の `poseActionsVersion: 1` と `poseActions` を保存元にする。
武器画面用の動作コピー、別の装備英文配列、別の選択済み主動作フラグは保存しない。
UIが編集中のインスタンスIDを保持し、変更時はそのIDだけを置換する。

```json
{
  "poseActionsVersion": 1,
  "poseActions": [{
    "id": "pa-uuid",
    "action": "pull",
    "weaponAction": "bow-aim",
    "use": {"kind": "equipment", "field": "weapon", "id": "bow"},
    "target": {"kind": "equipment", "field": "weapon", "id": "bow", "part": "bowstring"},
    "aim": {"kind": "creature", "id": "creature-uuid"},
    "movingPart": "both-hands",
    "direction": "body-left",
    "weight": 1.2
  }],
  "weaponFamilies": {"custom relic": "staff"}
}
```

最小の任意拡張:

- 動作の `weaponAction`: 共通構造化動作の意味の細分（プリセットID）。`action` と一致し、系統に適合するときだけ英文を生成する。
- 動作の `aim`: 弓弦を直接対象とする `pull` の照準先。既存の参照形式を共用。
- 動作の `grip`: `normal` / `reverse`。
- 所有者の `weaponFamilies`: 独自武器value → 系統。通常人物と人型Creatureのcapture/restoreに対応。

`use`、`target`、`aim` の役割は別。装備参照のIDは従来どおりfield内のvalue。
相手は人物/CreatureのIDで参照する。同名・同種でもラベル（Character/Creature A等）を表示して区別する。
装備解除後も参照は残し、対象武器不在を表示して出力を止める。他の武器へ付け替えない。
不在・削除済み・自己参照の任意の相手は英文から省略し、本人と使用武器の動作を保持する。

`raise`、`swing`、`thrust`、`pull`、`defend`、`throw`、`open`、`cross`、`support`、`cup` を再利用する。
照準、矢つがえ、射出、射撃、抜刀・納刀、魔法具発動、ページ、浮遊などは共通動作定義へ追加。
`paDefinition` / `paProblem` / `paPhrase` / `paTags` が両UIに対応する。

漫画は既存のコマ別 `actionTarget` を相手の上書きとして扱い、弓では `aim` に適用する。
弓弦の `target` は変えない。コマ別人物ポーズがあっても武器動作は残す。
出力fingerprintは生成英文から既存方式で算出する。
Undo、通常の自動/名前付き保存、JSON、履歴は既存snapshotを使用。
ID remapに `aim` を追加し、CreatureのhumanProfileのremapにも既存の経路で適用する。相手参照の検出は通常人物と人型Creatureの両モードを対象にし、Creatureだけの構成でも扱う。

## 両立・旧データ

同じ武器の主動作の切替は編集中のIDだけを更新。
既存の複数動作は保持し、対象を選べるようにする。
背負う等と使用動作が競合した場合は内容を示し、「構える」へ変更して適用するか取消を選ぶ。
この複合変更もUndoは1回。別武器の携帯と使用は競合しない。

旧weaponStateの6valueは変更しない。
武器を推測して割り当てず「以前の共通状態」に残す。
ユーザーが指定した武器へ移すときだけ、旧値を削除して同じ重み・以前の色を新しい動作へ移す。英文を編集した旧状態は意味を安全に変換できないため、共通状態に残して移行ボタンを無効にする。
旧ポーズの移行判定、編集英文を保持する条件、グループと移行元情報は既存処理を維持する。
現在の旧→新の移行を繰り返しても二重化しない。

保存namespaceと全体のJSONバージョンは変更していない。
旧JSONは拡張がなくても読める。新JSONを旧HTMLで編集することは非対応。
旧HTMLでは新動作が出力されない、または再利用された基本動作だけの意味になり得る。
`weaponFamilies` を含む人型Creatureは旧版の厳格な外見schemaで拒否され得る。
通常人物の「基本外見」形態は従来どおり外見専用で、ポーズを含めない。人型Creatureの形態captureは新動作と系統を保持する。

## ビルド・検証

`scripts/build-current.py` の現行方式を維持し、保守モジュールを同じscriptへ依存順に連結する。
37scriptの境界とSHA検証は維持。製品HTMLをビルド入力にはしない。
新しい関数wrapperを追記して既存の振る舞いを上書きする方式は追加していない。

```sh
npm ci
npm run build:check
npm run test:quality
npm run test:weapons
npm run test:audit
npm run test:remaining
npm run test:stability
```

合成データと新規ブラウザ領域だけを使用する。結果は最終製品SHAと共に記録する。

最終実行結果とAndroid確認用HTMLはPRと検証記録に添付する。
