## v44の仕様とmainの保護

「キャラ固有」は他キャラの候補も選べる仕様です。空を編集中にフリーナの上着を選択し、空の人物IDとフリーナ側のプロフィールを保持できました。
すべて／選択中／お気に入り／固有の切替、OFF後の選択保持と×解除、人物→携帯品→全体衣装→人物の往復を実操作で確認しています。
固有候補がない人物についても所有者一致を要求しません。古いown-onlyのテスト期待を復活させていません。

既存mainのカタログ3,218行は全フィールドを照合し、既存人物1,405件、基本外見1,399 owner、固有形態19件を保持しています。
東京喰種21名・赫眼8形態、遊戯王14名の表示統一、ペルソナ10名、怪異6構造も確認対象です。
基本外見の未定義は既存の一般人物5行と丹恒・飲月1行です。前者は一般タグ、後者は既存データの不足で、今回推測による外見追加を行っていません。

形態の選択と適用、所有記録、手動設定の保護、Undo、5保存キーそれぞれの障害時rollbackは既存テストを利用します。
保存namespace、settings v5／working v2／actorExtensions v4／horror v1を維持します。バックアップJSONの版と個々の保存コンポーネントの版を混同しません。
旧JSON v3/v4/v5、独自人物・同種CreatureのUUID、構造化ポーズ・色・重み・未知の任意値も互換試験の対象です。

## プロンプト構文と外部サービス

コードの7系列はサービスのチェックポイント版と同じ情報ではありません。noneでも人数やネガティブ補助が残る場合があり、「補正ゼロ」とは説明しません。
通常画像の内部Character/Creatureラベル漏れ、動作の空対象、関係の逆転・自己参照・不在参照を検査し、漫画では必要な識別子を残しています。
`BREAK`・ラベル・自然文・括弧だけで属性混線を必ず防げるとは保証しません。

出力の実例として、noneでも人物2名には `2 people`・`2girls` と補助ネガティブが残ります。一方、同種Creature2体は別ブロック・別属性・`subject 1/2` の参照で表現され、必ずしも総数タグが付く構成ではありません。
同種2体にも `duplicate creature` 等の補助が残ります。また、視線の自然文に作品名の括弧が残る例があります。これらのサービス側解釈は未確定で、数値weightや識別タグと区別して実画像で評価する必要があります。
今回の出力試験は、属性・参照・存在判定と正負文字列の検査です。これらの曖昧さを未測定のまま「矛盾なし」「描き分け成功」とは判断しません。

一次資料は2026-10-25 UTCにHTTP取得しました。取得記録は `validation/v44-audit/official-reference-fetch.json` です。

- [PixAI Prompt basics](https://docs.pixai.art/docs/prompts/prompt-basics)：モデルごとに推奨表現・既定補助が異なる。ツールの7系列すべての対応表を提供する資料ではありません。
- [PixAI Wiki Prompt Emphasis](https://wiki.pixai.art/en/w/Prompt-Weighting)：数値weightの不安定さ、括弧、DiTでの自然文を案内。
- [PixAI SDXL guide](https://blog.pixai.art/en/pixai-sdxl-prompting-guide-essential-tips-tricks/)：数値weightを案内する旧記事も存在。世代・モデル・処理が異なる可能性があり、全サービスで同じ仕様とは断定しません。
- [SeaArt公式ガイド](https://docs.seaart.ai/guide-1/espanol/4-parametros/4-7-edicion-de-prompts-or-guia-de-fusion-de-palabras-clave)：weight・括弧・エスケープ等を説明。モデル依存の注意があり、7系列の一律保証の根拠にはしません。

今回、SeaArt・PixAIで画像は生成していません。チェックポイント、LoRA、seed、サービス側補助を固定した実画像試験が別途必要です。
