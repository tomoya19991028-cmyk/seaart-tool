# v44 Android実機・外部生成の確認


最初に、**現在利用中の画面から設定JSONを書き出して保護してください**。名前付き保存・履歴・画像・下書き・未保存編集も別に保護します。
Android確認版HTMLは検証済みindex.htmlと同一バイトです。元commit・bytes・SHAは同梱のSHA256.jsonにあります。
ダウンロードHTMLを開く確認と、インストール済みPWAの更新・offline確認は別工程です。今回はPWAを公開更新していません。

| 短い確認 | 期待する結果 |
| --- | --- |
| 空でキャラ固有からフリーナの上着を選ぶ | 空のままで適用し、選択中表示と×解除ができる |
| 人物→携帯品→全体衣装→人物を素早く往復 | 固有ボタンが消えず、1個だけ動作する |
| 髪・光・エフェクトを切り替える | 配置と選択色が残る |
| 同じ動作を別の部位・対象へ追加 | 独立した指定になり、走り方を変えても対象が残る |
| 位置関係・視線を設定して生成し、対象を削除 | 主語・対象が意図どおりで、別相手へ勝手に置換しない |
| 横画面・文字拡大・キーボード表示 | 文字が切れず、カード・候補までスクロールできる |
| 名前付き保存・JSON・履歴・再起動 | 人物・Creature・動作・視線・漫画が復元される |
| CSVを往復、簡易漫画で専用JSONを保存 | 引用符・改行・BOMが保たれ、mainと専用保存が独立する |

簡易漫画は専用の「保存・読み込み」→「JSONバックアップ」を使います。mainのJSONは専用UI全体のバックアップではありません。
画像合成の元画像と配置はセッション専用です。必要な元画像・合成PNGを別に保存します。
新しい構造化ポーズ付き人型Creatureを旧mainへ戻せるとは保証しません。更新前JSONとコード復旧を別に扱います。

このPRでは実機・実IME・SeaArt/PixAI画像生成を実施していません。main・公開PWAも更新しません。
公開前にPRと自動試験の未解決結果を確認し、公開承認を別途取得してください。
